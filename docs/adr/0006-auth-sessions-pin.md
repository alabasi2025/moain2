# ADR-0006: جلسات KV + PIN للأجهزة الموثوقة

**الحالة:** مقبول

## السياق
موظفو الفروع يفتحون التطبيق يومياً من نفس الجوال. كلمة مرور طويلة كل مرة = لن يستخدموه. لكن الجهاز قد يُترك مفتوحاً أو يُفقد.

## القرار
- دخول أول بكلمة مرور (Argon2id) → جهاز موثوق + جلسة KV (cookie HttpOnly، 30 يوماً منزلق).
- PIN 4–6 أرقام مرتبط بـ (مستخدم + جهاز). قفل خمول 5 دقائق → PIN.
- Rate limit صارم. إلغاء الجهاز من لوحة الأدمن = قطع فوري.

## البدائل المرفوضة
- **JWT**: لا يُلغى فوراً.
- **Clerk/Auth0/Supabase Auth**: تكلفة شهرية، اعتماد خارجي، لا PIN لكل جهاز بشكل أصلي.
- **Passkeys/WebAuthn**: ممتاز ومستقبلي — نضيفه في M3 كخيار بديل للـ PIN على الأجهزة الداعمة.
- **SMS OTP**: تكلفة وتعقيد في اليمن.

## العواقب
- (+) تجربة سريعة جداً، تحكم كامل، صفر تكلفة.
- (−) علينا بناء شاشات إدارة الأجهزة والجلسات — بسيطة.
