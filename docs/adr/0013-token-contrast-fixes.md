# ADR-0013: تصحيحات دنيا لتباين الرموز اللونية (WCAG AA)

**الحالة:** مقترح — بانتظار موافقة صاحب المشروع · **التاريخ:** 2026-10-03
**الدليل:** `docs/07-implementation/evidence/verify_token_contrast.py` و`token_fix_candidates.out.txt`

## السياق
`00-design-system.md` يشترط أن يكون كل زوج نص/خلفية ≥ 4.5:1، وأن يُفحص آلياً. القياس الفعلي لقيم الرموز كما كُتبت:

| الزوج | المقاس | المطلوب |
|---|---|---|
| `--ink-3` على `--bg` (caption/placeholder) | 2.81 | 4.5 |
| `--success` كنص على الأبيض | 4.08 | 4.5 |
| `--warning` كنص على الأبيض | 2.63 | 4.5 (و2.63 < 3 حتى كعنصر غير نصي) |
| `--info` كنص على الأبيض | 4.38 | 4.5 |
| داكن: `--ink-3` على `--surface` | 4.44 | 4.5 |
| داكن: نص أبيض على `--brand-500` (58%) = الزر الأساسي | 2.80 | 4.5 |
| داكن: `--brand-50` غير معرّف، فيرث 96% (بطاقة البطل) | 1.04 | 4.5 |

## القرار (مقترح)
الصبغات والأسماء تبقى، وتتغير الإضاءة فقط بأقل قدر يحقق AA:

```css
:root {
  --ink-3: hsl(30 8% 44%);                 /* كان 58% */
  --success-ink: hsl(152 55% 34%);         /* نص الحالة؛ --success للتعبئة يبقى */
  --warning-ink: hsl(38 92% 33%);
  --warning: hsl(38 92% 42%);              /* تعبئة غير نصية ≥ 3:1 */
  --info: hsl(210 70% 47%);
  --brand-fill: var(--brand-500);          /* خلفية الزر الأساسي */
  --brand-text: var(--brand-500);          /* نص بلون العلامة */
}
[data-theme="dark"] {
  --ink-3: hsl(36 8% 51%);
  --brand-fill: hsl(var(--brand-h) var(--brand-s) 42%);   /* أبيض عليه 4.6 */
  --brand-text: hsl(var(--brand-h) var(--brand-s) 58%);   /* على السطح الداكن 6.06 */
  --brand-50:  hsl(var(--brand-h) calc(var(--brand-s) * .7) 14%);
  --brand-100: hsl(var(--brand-h) calc(var(--brand-s) * .7) 18%);
  --brand-200: hsl(var(--brand-h) calc(var(--brand-s) * .7) 26%);
}
```

- اختبار CI يحسب التباين لكل زوج مستخدم (فاتح وداكن) ولكل لون مستأجر مُدخَل (`applyBrand` يُظلّم `--brand-fill` حتى 4.5 ويُفتّح `--brand-text` في الداكن).

## البدائل المرفوضة
- **الإبقاء على القيم:** يفشل معيار A11y ≥ 95 ويكسر قراءة النص الثانوي في ضوء الشمس (معمل/فرع).
- **تغيير الصبغات:** يغيّر الهوية الدافئة. غير ضروري.

## العواقب
- (+) AA في الوضعين، والهوية محفوظة.
- (−) النص الثانوي أغمق قليلاً — أوضح على الشاشات الرخيصة.
