# النشر — مُعين

| البند | القيمة |
|---|---|
| المنصة | Cloudflare Workers for Platforms (مُدار) + D1 |
| الرابط المباشر | _يُملأ بعد النشر_ |
| إعداد النشر | `wrangler.toml` في جذر المستودع |
| البناء | `pnpm install --frozen-lockfile && pnpm --filter @moain/web build` |
| قاعدة البيانات | الهجرات من `migrations/` في جذر المستودع (0000 → 0002) |

## أول تشغيل بعد النشر
1. البيانات الأولية للمنشأة التجريبية: `POST /api/v1/dev/seed` (يعمل فقط عند `DEMO=1`).
2. بيانات العرض (اختياري): `BASE=<الرابط>/api/v1 node packages/server/scripts/demo-data.mjs`.

## الإغلاق التلقائي للطلبيات
المنصة المُدارة لا تدعم مهام cron، لذلك يُفحص وقت الإغلاق تلقائياً مع الطلبات الواردة (مرة في الدقيقة كحد أقصى لكل نسخة) — انظر `packages/server/src/index.ts`. النتيجة نفسها: تُقفل الطلبيات بعد وقت الإغلاق ويُنشأ إصدار الطباعة.

## قبل التشغيل الفعلي (إلزامي)
- اضبط السر `PEPPER` (`gsk hosted secret_put --name PEPPER --value "$PEPPER"`) **قبل** إنشاء المستخدمين الحقيقيين.
- غيّر `DEMO` إلى `"0"` لتعطيل `/api/v1/dev/seed` وأزرار الدخول التجريبي.
- أنشئ منشأة العميل ومستخدميه الحقيقيين، واحذف الحسابات التجريبية.
