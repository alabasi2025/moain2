# القاموس الموحد (Ubiquitous Language)

> مصطلح واحد لكل مفهوم، في الكود والواجهة والوثائق والحديث مع العميل. أي مصطلح غير موجود هنا لا يُستخدم.

## الكيانات الأساسية

| عربي (الواجهة) | English (الكود) | التعريف | ملاحظات |
|---|---|---|---|
| **المستأجر** / الشركة | `Tenant` | شركة/مجموعة مخابز تملك حساباً مستقلاً | جذر العزل. كل شيء تحته |
| **الموقع** | `Location` | أي مكان فيزيائي: معمل، فرع، مخزن، عبور | `kind: plant \| branch \| warehouse \| transit` |
| **المعمل** | `Plant` | موقع يُنتج ويُجهّز الطلبيات | `Location.kind = 'plant'` |
| **الفرع** | `Branch` | موقع يطلب ويستلم ويبيع | `Location.kind = 'branch'` |
| **المخزن** | `Warehouse` | موقع يحفظ مواد خام | `Location.kind = 'warehouse'` |
| **التصنيف** | `Category` | تجميع شجري للمنتجات (معجنات → كرواسون) | عمق غير محدود |
| **المنتج** / الصنف | `Product` | منتج نهائي يُنتجه المعمل ويطلبه الفرع | ليس مادة خام |
| **المادة الخام** | `RawMaterial` | مادة تُشترى وتُخزَّن وتُستهلك في الإنتاج | دقيق، سكر، زبدة |
| **وحدة القياس** | `UoM` (Unit of Measure) | كجم، جم، لتر، حبة، كرتون | مع تحويلات اختيارية |
| **نافذة الطلب** | `OrderWindow` | فترة زمنية يُسمح فيها للفروع بالطلب لمعمل معين | لها وقت إغلاق |
| **وقت الإغلاق** | `CutoffTime` | آخر وقت يُقبل فيه الطلب في النافذة | بعده: استثناء فقط |
| **الطلبية** | `Order` | طلب فرع واحد لتاريخ تسليم واحد ضمن نافذة واحدة | وثيقة الفرع |
| **سطر الطلبية** | `OrderLine` | صنف + كمية + ملاحظة داخل طلبية | |
| **أمر الإنتاج** | `ProductionOrder` | تجميع كل طلبيات نافذة واحدة لمعمل واحد | وثيقة المعمل |
| **سطر أمر الإنتاج** | `ProductionLine` | صنف + الكمية الإجمالية المطلوبة + تفصيل الفروع | مشتق |
| **قسم الإنتاج** | `ProductionSection` | تقسيم أمر الإنتاج حسب تصنيف/مسؤول | اختياري |
| **التسليم** | `Delivery` | حدث تسليم طلبية (أو جزء منها) من المعمل للفرع | له توقيع |
| **سطر التسليم** | `DeliveryLine` | صنف + الكمية المُسلَّمة فعلياً | قد تختلف عن المطلوبة |
| **السند** | `Voucher` | وثيقة مخزنية مجمّعة (توريد أو صرف) تحتوي عدة أسطر | يُرحَّل ليولّد حركات |
| **سند توريد** | `ReceiptVoucher` | سند يُدخل مواد للمخزن | من مورد |
| **سند صرف** | `IssueVoucher` | سند يُخرج مواد من المخزن | لساحب |
| **حركة مخزنية** | `StockMovement` | سطر واحد في دفتر المخزون، غير قابل للتعديل | الحقيقة الوحيدة |
| **الدفتر** | `Ledger` | مجموع كل الحركات | `stock_movements` |
| **الرصيد** | `OnHand` / `Balance` | مجموع حركات مادة في موقع | مشتق، لا يُخزَّن |
| **حد الأمان** | `SafetyStock` / `ReorderPoint` | الرصيد الذي عنده يُنبَّه المسؤول | لكل مادة |
| **تكلفة الوحدة** | `UnitCost` | سعر شراء وحدة واحدة في حركة معينة | بالوحدات الصغرى |
| **سعر التقييم** | `ValuationRate` | المتوسط المرجّح المتحرك الحالي | يتغير مع كل وارد |
| **قيمة المخزون** | `StockValue` | الرصيد × سعر التقييم | مشتق |
| **رصيد أول المدة** | `OpeningBalance` | الرصيد عند بداية فترة التقرير | مشتق من الدفتر |
| **جلسة الجرد** | `CountSession` | عملية عدّ فعلي للمخزن | snapshot ثم فروقات |
| **سطر الجرد** | `CountLine` | مادة + المتوقع + المعدود | |
| **المورد** | `Supplier` | جهة نشتري منها المواد الخام | بسيط في M2 |
| **الساحب** | `Requester` / `IssuedTo` | الشخص/القسم الذي سحب المواد | نص + user_id اختياري |
| **الوصفة** | `Recipe` / `BOM` | قائمة المواد الخام لإنتاج وحدة منتج | M3 |
| **المستخدم** | `User` | شخص له حساب | |
| **الدور** | `Role` | مجموعة صلاحيات | |
| **الجهاز الموثوق** | `TrustedDevice` | جهاز سُجّل عليه الدخول ويُسمح بـ PIN | |
| **سجل التدقيق** | `AuditLog` | من غيّر ماذا ومتى | |
| **الإشعار** | `Notification` | رسالة للمستخدم عن حدث | |
| **الهوية** | `Branding` | شعار، ألوان، بيانات الشركة | |

## حالات الطلبية (`Order.status`)

| عربي | الكود | المعنى |
|---|---|---|
| مسودة | `draft` | الفرع يكتب ولم يرسل. محلي أو محفوظ |
| مُرسَلة | `submitted` | الفرع أرسل. تنتظر إغلاق النافذة |
| مُقفلة | `locked` | النافذة أُغلقت. لا تعديل إلا باستثناء |
| قيد الإنتاج | `in_production` | المعمل بدأ |
| جاهزة | `ready` | المعمل أنهى. تنتظر التسليم |
| مُسلَّمة جزئياً | `partially_delivered` | وصل بعضها |
| مُسلَّمة | `delivered` | وصلت كاملة ووُقّع عليها |
| ملغاة | `cancelled` | أُلغيت (مع سبب) |

## حالات أمر الإنتاج (`ProductionOrder.status`)

| عربي | الكود | المعنى |
|---|---|---|
| مفتوح | `open` | النافذة مفتوحة، يتجمّع |
| مُقفل | `locked` | النافذة أُغلقت، جاهز للطباعة |
| قيد التنفيذ | `in_progress` | بدأ الإنتاج |
| مكتمل | `completed` | كل شيء أُنتج |
| مُسلَّم | `delivered` | كل الطلبيات سُلِّمت |
| ملغى | `cancelled` | |

## حالات السند (`Voucher.status`)

| عربي | الكود | المعنى |
|---|---|---|
| مسودة | `draft` | يُكتب، لم يؤثر على المخزون |
| مُرحَّل | `posted` | ولّد حركات. غير قابل للتعديل |
| ملغى | `cancelled` | ولّد حركات عكسية |

## أنواع الحركة (`StockMovement.reason`)

| عربي | الكود | الإشارة | المصدر |
|---|---|---|---|
| رصيد افتتاحي | `opening` | + | إعداد أولي |
| توريد | `receipt` | + | سند توريد |
| صرف | `issue` | − | سند صرف |
| تسوية | `adjustment` | ± | تسوية يدوية بسبب |
| جرد | `count` | ± | جلسة جرد |
| تحويل | `transfer` | ± (زوج) | بين موقعين |
| مرتجع | `return` | + | مرتجع من إنتاج أو − مرتجع لمورد |
| هالك | `waste` | − | تالف/منتهي |
| عكس | `reversal` | ± | إلغاء سند |

## الأدوار (`Role`)

| عربي | الكود | يستطيع |
|---|---|---|
| المالك | `owner` | كل شيء + الفوترة + حذف المستأجر |
| المدير | `admin` | كل شيء عدا الفوترة |
| مدير المعمل | `plant_manager` | أوامر الإنتاج، التعيين، الطباعة، التسليم، تقارير المعمل، الموافقة على الاستثناءات |
| موظف المعمل | `plant_staff` | عرض أوامر الإنتاج، الطباعة، تسجيل التسليم |
| مستخدم الفرع | `branch_user` | طلبيات فرعه فقط، استلام، عرض حالة |
| أمين المخزن | `storekeeper` | السندات، الحركات، الجرد، تقارير المخزون |
| مُشاهد | `viewer` | قراءة فقط للتقارير |

## مصطلحات محظورة (لتجنّب الالتباس)

| لا تقل | قل بدلاً منها | السبب |
|---|---|---|
| "الكمية" (بدون سياق) | "الكمية المطلوبة" / "المُسلَّمة" / "الرصيد" | ثلاثة معانٍ مختلفة |
| "الصنف" للمادة الخام | "المادة الخام" | الصنف = منتج نهائي فقط |
| "الطلب" لأمر الإنتاج | "أمر الإنتاج" | الطلب = من الفرع فقط |
| "تعديل الرصيد" | "تسجيل تسوية" | الرصيد لا يُعدَّل، يُسجَّل عليه حركة |
| "حذف الحركة" | "عكس الحركة" / "إلغاء السند" | لا حذف في الدفتر |
| "المخزن" للمعمل | "المعمل" | مواقع مختلفة بأدوار مختلفة |
| "الفاتورة" | "سند التوريد" (+ رقم فاتورة المورد كحقل) | الفاتورة وثيقة المورد، السند وثيقتنا |
