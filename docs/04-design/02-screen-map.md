> كل دور يرى تطبيقاً مختلفاً. نفس الكود، تبويبات مختلفة. المستخدم بأدوار متعددة يرى اتحاد التبويبات (حتى 5) أو مبدّل سياق.

## 3. التدفقات الرئيسية

### F1 — الفرع يرسل طلبية الغد (الهدف: < 90 ثانية لـ 20 صنفاً)
```
فتح التطبيق (PIN إن لزم) 
→ الرئيسية: بطاقة "طلبية الغد — تُغلق خلال 3س" [ابدأ الطلبية] 
→ /order: 
   (اختياري) "نسخ طلبية أمس؟" → نعم → الكميات تُملأ 
   الأقسام مفتوحة: المعجنات (8 أصناف) ... 
   لكل صنف: نقر + أو نقر الرقم → NumberPad → تم 
   ملاحظة صنف: ضغط مطوّل → sheet ملاحظة 
   StickyActionBar: "23 صنفاً · 1,240 وحدة" [مراجعة وإرسال] 
→ /order/review: الأصناف المختارة فقط + ملاحظة عامة [إرسال] 
→ Toast "تم الإرسال ✓" + haptic → الرئيسية: "طلبية الغد مُرسَلة · يمكنك التعديل حتى 10:00 م"
```

### F2 — المعمل يطبع أمر الإنتاج
```
فتح → الرئيسية: "أمر اليوم مقفل · 5 فروع · 1,240 وحدة" [افتح] 
→ /production/:id: المصفوفة. تعيين المسؤول (inline) والوقت المتوقع 
→ FAB طباعة → Sheet: [مجمّع] [حسب القسم] [حسب الفرع] + [خط كبير ☐] 
→ /print/production/:id?layout=... → معاينة → طباعة
→ (لاحقاً) [بدء الإنتاج] → الفروع تُشعَر
```

### F3 — التسليم بتوقيع
```
/deliver → فرع الستين (جاهزة) 
→ الكميات مملوءة بالمطلوب؛ تعديل إن نقص 
→ اسم المستلم (آخر مستلم مقترح) 
→ SignaturePad → [تأكيد التسليم] 
→ Toast + إيصال قابل للطباعة + الفرع يُشعَر "تم تسليم طلبيتك"
```

### F4 — أمين المخزن يسجّل وارداً سريعاً (الهدف: < 40 ثانية)
```
/ → [وارد ↓] 
→ المادة: بحث "دقيق" → دقيق فاخر 
→ الكمية: NumberPad 50 → السعر للوحدة: 800 (آخر سعر مقترح) → المورد (آخر مورد مقترح) → رقم الفاتورة 
→ [إضافة مادة أخرى] أو [ترحيل] 
→ Toast "RCV-2026-00017 ✓ · رصيد الدقيق الآن 150 كجم"
```

### F5 — الجرد
```
/counts → [جرد جديد] → المخزن المركزي · كامل → snapshot 
→ قائمة المواد (المتوقع مخفي = جرد أعمى اختياري) → NumberPad لكل مادة 
→ [إنهاء العدّ] → مراجعة: الفروقات ملوّنة، تحذير إن حدثت حركات أثناء الجرد 
→ [اعتماد] → حركات count → Toast
```
