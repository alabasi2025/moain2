# نظام التصميم — "مُعين"

> الفخامة = هدوء + دقة + اتساق. لا تدرجات صارخة، لا ظلال ثقيلة، لا زخرفة. كل بكسل له سبب.
> المرجع الذهني: تطبيقات البنوك الحديثة (Revolut/STC Pay) × أدوات التشغيل (Linear) × دفء المخبز.

## 1. الشخصية البصرية

| الصفة | التعبير |
|---|---|
| **دافئ** | لوحة محايدة دافئة (كريمي/رملي) لا رمادي بارد. اللون الأساسي بني-ذهبي (خبز) قابل للتبديل بلون العميل |
| **واثق** | مسافات سخية، نص كبير واضح، أرقام بارزة. لا ازدحام |
| **دقيق** | شبكة 4px صارمة، أرقام tabular، حدود 1px هادئة، زوايا متسقة |
| **حيّ** | حركة 150–300ms طبيعية (ease-out)، haptics خفيفة، تحديثات لحظية بدون وميض |
| **عربي أصيل** | RTL من الجذر لا "مقلوب". خط عربي مصمم للشاشة. أرقام واضحة |

## 2. الرموز (Design Tokens)

**قاعدة التباين:** كل زوج نص/خلفية ≥ 4.5:1 (AA). `--ink` على `--bg` = 13:1. `--ink-2` على `--surface` = 6.2:1. `--brand-500` على أبيض = 5.1:1 (يصلح للنص). يُفحص آلياً في Storybook.

**لون المستأجر:** الأدمن يختار لوناً → نستخرج H وS → كل درجات `--brand-*` تُشتق تلقائياً → نفحص التباين → إن فشل `--brand-500` كنص، نُظلّمه تلقائياً حتى يمر.

### 2.2 الخطوط

```css
:root {
  --font-ui: 'IBM Plex Sans Arabic', system-ui, -apple-system, 'Segoe UI', sans-serif;
  --font-display: 'Cairo', var(--font-ui);
  --font-mono: 'IBM Plex Mono', ui-monospace, monospace;   /* أكواد، أرقام سندات */
}
```

| الرمز | الحجم/السطر | الوزن | الخط | الاستخدام |
|---|---|---|---|---|
| `display` | 28/36 | 700 | Cairo | عنوان الشاشة الرئيسية، الأرقام الكبيرة في اللوحة |
| `h1` | 22/30 | 600 | Plex | عنوان الشاشة |
| `h2` | 18/26 | 600 | Plex | عنوان قسم |
| `h3` | 16/24 | 600 | Plex | عنوان بطاقة |
| `body` | 16/24 | 400 | Plex | النص الأساسي (16px حد أدنى على الجوال — يمنع zoom في iOS) |
| `body-strong` | 16/24 | 500 | Plex | تسميات |
| `small` | 14/20 | 400 | Plex | ثانوي |
| `caption` | 12/16 | 400 | Plex | شارات، تواريخ |
| `num-lg` | 24/28 | 600 | Plex tabular | الكميات في الـ stepper |
| `num` | 16/24 | 500 | Plex tabular | الأرقام في الجداول |

قواعد: `font-variant-numeric: tabular-nums` على كل رقم. حد أدنى 16px للمدخلات (iOS). دعم Dynamic Type حتى 200% (نستخدم `rem`).

### 2.3 المسافات — شبكة 4px

```
--sp-1: 4px   --sp-2: 8px   --sp-3: 12px  --sp-4: 16px
--sp-5: 20px  --sp-6: 24px  --sp-8: 32px  --sp-10: 40px  --sp-12: 48px
```
- هامش الشاشة الجانبي: 16px (جوال)، 24px (تابلت)، محتوى بعرض أقصى 1200px على الكمبيوتر.
- بين البطاقات: 12px. داخل البطاقة: 16px.
- بين أهداف اللمس: ≥ 8px.

### 2.4 الزوايا

```
--r-sm: 8px    (شارات، مدخلات صغيرة)
--r-md: 12px   (أزرار، مدخلات، صفوف)
--r-lg: 16px   (بطاقات)
--r-xl: 24px   (sheets، modals)
--r-full: 999px (pills، avatar)
```

### 2.5 الارتفاع (Elevation) — ظلال هادئة

```
--e-0: none                                              (مسطّح — الافتراضي)
--e-1: 0 1px 2px hsl(30 20% 12% / .06)                  (بطاقة)
--e-2: 0 4px 12px hsl(30 20% 12% / .08)                 (مرفوع: FAB، dropdown)
--e-3: 0 12px 32px hsl(30 20% 12% / .14)                (sheet, dialog)
```
نفضّل **الحدود والسطوح** على الظلال. الظل للعناصر العائمة فقط.

### 2.6 الحركة

```
--dur-fast: 120ms    (hover, press, toggle)
--dur-base: 200ms    (fade, slide-in صغير)
--dur-slow: 300ms    (sheet, page transition)
--ease-out: cubic-bezier(0.2, 0, 0, 1)      (دخول — يبدأ سريعاً ويهدأ)
--ease-in: cubic-bezier(0.4, 0, 1, 1)       (خروج)
--ease-spring: cubic-bezier(0.34, 1.4, 0.64, 1)  (نقرة تأكيد خفيفة — نادر)
```
- `prefers-reduced-motion` → كل المدد 0ms، لا parallax.
- فقط `transform` و`opacity`.
- الانتقال بين الشاشات: الشاشة الجديدة تدخل من اليسار (RTL!) مع fade؛ الرجوع عكسها.
- Sheet من الأسفل: slide-up 300ms ease-out + خلفية تُعتم.
- الضغط على زر: `scale(0.97)` 120ms.
- ظهور عنصر في قائمة: fade+slide 8px، stagger 30ms (حتى 10 عناصر).

### 2.7 الأيقونات
Lucide، 24px افتراضي (20px في النص الكثيف)، stroke 1.75. الأسهم الاتجاهية تنقلب في RTL تلقائياً (`rtl:-scale-x-100`). أيقونة + نص دائماً في التنقل الرئيسي.

## 3. المكونات

### 3.1 الأساسية (Primitives) — فوق Radix

| المكون | المواصفات |
|---|---|
| **Button** | ارتفاعات: `lg` 56px (CTA رئيسي)، `md` 48px (افتراضي)، `sm` 40px (داخل الجداول فقط). أنواع: `primary` (brand ممتلئ)، `secondary` (surface-2 + حد)، `ghost`، `danger`. حالة تحميل: النص يبقى + دوّار صغير بجانبه (لا يختفي النص). عرض كامل على الجوال للـ CTA |
| **IconButton** | 48×48 هدف لمس، أيقونة 24. دائري أو `r-md` |

## 4. الشبكة والتجاوب

| النقطة | العرض | التخطيط |
|---|---|---|
| `mobile` | < 640 | عمود واحد، BottomNav، Sheets، بطاقات |
| `tablet` | 640–1023 | عمودان حيث يفيد، BottomNav يبقى أو Rail 80px، Sheets |
| `desktop` | ≥ 1024 | Sidebar 260px، محتوى ≤ 1200px، Dialogs، DataTable كاملة، لوحة جانبية للتفاصيل |

**Mobile-first**: نصمم للجوال ثم نوسّع. لا نصمم للكمبيوتر ثم نضغط.

## 5. الصوت والاهتزاز
- `navigator.vibrate(10)` عند: نجاح إرسال/ترحيل، إكمال قسم. `[10,30,10]` عند خطأ. لا اهتزاز على كل نقرة.
- لا أصوات افتراضياً. خيار صوت "تنبيه طلبية جديدة" للمعمل (قابل للتفعيل).

## 6. الوضع الداكن
مدعوم من اليوم الأول عبر tokens. يتبع النظام افتراضياً + تبديل يدوي. الطباعة دائماً فاتحة.

## 7. اللغة والاتجاه
- `<html lang="ar" dir="rtl">`. كل CSS بـ logical properties.
- النصوص في `locales/ar.json` حتى الافتراضية — لا نص ثابت في الكود.
- الأرقام: `Intl.NumberFormat('ar-YE' | 'en')` حسب إعداد `numerals`.
- التواريخ: `Intl.DateTimeFormat` بالمنطقة الزمنية؛ نسبي للقريب ("قبل 5 دقائق"، "أمس 10:30 م").
- الجمع العربي: "صنف واحد / صنفان / 3 أصناف / 11 صنفاً" — دالة `plural(n, forms)`.

## 8. الوصولية (إلزامي)
- كل عنصر تفاعلي ≥ 48×48 بمسافة ≥ 8.
- تباين ≥ 4.5:1 نص، ≥ 3:1 عناصر.
- `aria-label` عربي على كل IconButton.
- ترتيب التركيز منطقي؛ Sheet يحبس التركيز (Radix).
- دعم VoiceOver/TalkBack: الحالات تُقرأ ("كرواسون، الكمية 40، زر زيادة").
- `prefers-reduced-motion` و`prefers-contrast` محترمان.
- Dynamic Type 200% بدون كسر (اختبار Playwright بـ `font-size: 200%`).
