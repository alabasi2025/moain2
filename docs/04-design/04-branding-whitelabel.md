# الهوية والعلامة القابلة للتخصيص (White-label)

> المنتج اسمه "مُعين". لكن العميل يرى **شركته** — شعاره، لونه، اسمه — في كل مكان: الأيقونة، الشاشة، الطباعة، Excel، الإشعارات.

## 1. ما يُخصَّص

| العنصر | المصدر | أين يظهر |
|---|---|---|
| اسم الشركة (عربي/إنجليزي) | `tenant_branding.company_name(_en)` | Header، Splash، PIN، كل مستند مطبوع، Excel، عنوان الإشعارات، `<title>` |
| الشعار | `logo_url` (R2) | Header (32px)، Splash (192px)، PIN (80px)، الطباعة (رأس كل صفحة)، Excel (A1)، أيقونة التطبيق (مُولَّدة) |
| شعار الطباعة | `logo_print_url` اختياري | نسخة أحادية/عالية الدقة للطباعة بالأبيض والأسود |
| اللون الأساسي | `primary_color` | كل `--brand-*` تُشتق منه. رؤوس الجداول المطبوعة، شريط العنوان، Excel headers، `theme_color` |
| لون التمييز | `accent_color` | لمسات خفيفة (شارات مميزة، sparkline) |
| نص التذييل | `footer_text` | أسفل كل مستند مطبوع ("شكراً لتعاملكم" / شروط) |
| الهاتف والعنوان | `phone`, `address` | رأس المستندات |
| الرقم الضريبي | `tax_number` | رأس السندات إن وُجد |

## 2. آلية اللون الديناميكي

```ts
// lib/theme/brand.ts
export function applyBrand(hex: string) {
  const { h, s, l } = hexToHsl(hex);
  const root = document.documentElement;
  root.style.setProperty('--brand-h', String(h));
  root.style.setProperty('--brand-s', `${s}%`);
  // --brand-500 يُشتق تلقائياً في CSS. نفحص التباين:
  const onWhite = contrast(hsl(h, s, 42), '#fff');
  if (onWhite < 4.5) {
    // نُظلّم حتى يمر — نحافظ على الصبغة
    let L = 42; while (contrast(hsl(h, s, L), '#fff') < 4.5 && L > 20) L -= 2;
    root.style.setProperty('--brand-500', `hsl(${h} ${s}% ${L}%)`);
  }
  // theme-color للمتصفح/PWA
  document.querySelector('meta[name=theme-color]')?.setAttribute('content', cssVar('--bg'));
}
```
- يُطبَّق عند تحميل `/auth/me` وقبل أول رسم (inline script يقرأ آخر قيمة من localStorage لتجنب الوميض).
- الأدمن يرى معاينة حية أثناء اختيار اللون + تحذير "هذا اللون فاتح جداً للنص — سنُظلّمه تلقائياً في الأزرار".
- ألوان الحالات (نجاح/خطأ/تحذير) **لا تتغير** — معناها عالمي.

## 3. أيقونة التطبيق الديناميكية

المشكلة: `manifest.json` ثابت، لكن كل مستأجر يريد أيقونته.

الحل:
```
GET /m/:tenantSlug/manifest.webmanifest   → Worker يولّد manifest ديناميكياً:
  name: company_name, short_name, theme_color: primary, background_color: --bg,
  icons: [/m/:slug/icon-192.png, /m/:slug/icon-512.png, /m/:slug/icon-maskable-512.png],
  shortcuts, start_url: /?tenant=:slug

GET /m/:slug/icon-:size.png → Worker: يأخذ الشعار من R2، يضعه على خلفية primary (أو بيضاء)
  بحشوة 20% (maskable safe zone)، يُعيد PNG (Cloudflare Images / resvg-wasm). كاش طويل.
```
- `<link rel="manifest" href="/m/alnoor/manifest.webmanifest">` يُحقن حسب المستأجر (من slug في URL أو cookie).
- iOS: `apple-touch-icon` → نفس المسار. Splash → مُولَّد لكل حجم شاشة (~12 صورة) من نفس Worker مع كاش.
- إن لم يرفع العميل شعاراً: أيقونة "مُعين" الافتراضية بلونه + أول حرف من اسم الشركة.

## 4. الشعار — المتطلبات والمعالجة

| | |
|---|---|
| الصيغ المقبولة | PNG, SVG, JPG, WebP (≤ 2MB) |
| المعالجة | إعادة ترميز إلى WebP + PNG، أحجام: 64, 192, 512، إزالة metadata. SVG يُنظَّف (sanitize) |
| التخزين | R2 `branding/{tenant}/logo-{size}.{ext}` + `logo-print.png` |
| الخلفية | يُفضَّل شفاف. إن كان JPG بخلفية بيضاء → نعرضه على بطاقة بيضاء دائماً |
| الطباعة | إن لم يُرفع `logo_print`، نستخدم 512 الملوّن (الطابعات الحديثة تطبعه جيداً بالرمادي) |

## 5. "Powered by مُعين"

- في الواجهة: سطر صغير في شاشة "المزيد" فقط ("مُعين · الإصدار 1.2").
- في الطباعة: تذييل بخط 7pt رمادي "نظام مُعين" — قابل للإخفاء في الخطة المدفوعة الأعلى.
- في Excel: لا (مستند العميل).
- لا شعار "مُعين" يزاحم شعار العميل أبداً.

## 6. الهوية الافتراضية لـ "مُعين" (عندما لا يوجد مستأجر — صفحة الدخول العامة)

| | |
|---|---|
| الاسم | مُعين — بالضمة على الميم (يُقرأ Mu'een). المعنى: المساعد الموثوق |
| الشعار | رمز بسيط: رغيف/قوس خبز هندسي يتحول لعلامة ✓ — خط واحد، يعمل بـ 16px |
| اللون | بني-ذهبي `hsl(28 42% 42%)` ≈ #8B5E3C + ذهبي #D4A056 |
| الخط | Cairo Bold للاسم |
| النبرة | محترف، دافئ، مباشر. "تم الإرسال ✓" لا "تمت العملية بنجاح!" |
